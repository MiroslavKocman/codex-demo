# Codex demo instructions

This is a small Python learning repository, prepared for Codex Cloud.

- Use Python 3.10 or newer and the standard library. No dependency installation is needed.
- Run `python3 scripts/check.py` before and after changing code (on Windows, use `python`).
- `text_stats.py` is the sample application; `tests/test_text_stats.py` tests its behaviour and CLI.
- `hello.py` is the original independent greeting example. It is interactive; do not run it without supplying input.
- Keep CLI output machine-readable JSON. Send errors to stderr with a nonzero exit code.
- For requested behaviour changes, add relevant tests and update the README.
- Do not implement exercises from `EXERCISES.md` unless the user asks for that exercise.
- Summarize the change and actual test results in Czech. Clearly state checks you could not run.
